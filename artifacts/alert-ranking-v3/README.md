# Alert-ranking v3 final artefact

`alert_rankings_rag.json` is the final, public-safe output of the 21 August 2026 alert-ranking
run described in the internship report and presentation. It contains 50 distinct Snort alert
results generated with `openai/gpt-oss-120b`.

## Recorded fields

Each record includes:

- the alert id, short message, classification, and Snort priority;
- the deterministic anchored rank and the model-selected rank;
- the model justification and any mismatch explanation;
- the retrieved SID match outcome; and
- the independent judge verdict.

## Reproduction and publication boundary

The file is generated by `scripts/build_alert_rag_report.py` from the private run snapshots
and 50-alert sample. Those source snapshots are not published because they include retrieved
passages from standards and Cisco rule documentation. This curated output keeps the derived
rankings, explanations, SID comparisons, and judge results without redistributing the source
documents or exposing API keys, local paths, or full retrieved passages.
